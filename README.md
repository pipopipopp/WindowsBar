# WDZ – Secondary Windows Taskbar

Aplicação desktop desenvolvida em C# que adiciona uma segunda barra ao Windows utilizando `NotifyIcon` e integração com a bandeja do sistema.

---

## 🚀 Funcionalidades

- Segunda barra fixa na tela
- Ícone na bandeja do sistema
- Menu de contexto
- Execução em segundo plano
- Inicialização leve e discreta

---

## 🛠 Tecnologias

- C#
- .NET
- Windows Forms

---

## 🎯 Objetivo

Projeto experimental focado em:

- Manipulação de interface no Windows
- Uso de `NotifyIcon`
- Estrutura de aplicação desktop
- Organização de projeto para produção
